# 주식 기록 수집기 (맥북 전용)

`stocks.html` 화면에 들어갈 기록을 만드는 맥북 쪽 도구입니다.
매일 08:30에 매매 계획을 고정하고, 장 마감 후 그 계획을 분봉으로 그대로 재현해 채점합니다.

## 설계의 핵심: 70%를 희망이 아니라 관문으로

목표 적중률 70%는 "그렇게 되면 좋겠다"가 아니라 **통과 조건**입니다.

- 셋업(조건 조합)마다 실제 적중률을 계속 기록합니다
- 그 적중률의 **Wilson 95% 하한**이 70%를 넘는 셋업만 추천으로 내보냅니다
- 넘지 못하면 그날은 **추천 0개**. 5개를 억지로 채우지 않습니다
- 표본 30건 미만은 '관찰 중'으로 두고 추천하지 않습니다

단순 비율이 아니라 Wilson 하한을 쓰는 이유: 10건 중 8건(80%)은 표본이 적어 우연일 수 있습니다.
Wilson 하한은 표본이 적을수록 값을 크게 깎습니다. 10건 중 8건이면 하한 약 49%,
100건 중 80건이면 약 71%입니다. 운 좋은 소수 표본이 관문을 통과하지 못합니다.

**적중의 정의**: 수수료·거래세·슬리피지를 뺀 뒤에도 수익이 남은 거래.
목표가에 닿기만 한 것은 적중이 아닙니다.

### 승률과 목표는 맞바꾸는 관계입니다

| 승률 | 목표 | 손절 | 거래당 기대값 (비용 전) |
|---|---|---|---|
| 70% | +3% | −1.5% | +1.65% — 세계 최상위 수준. 기대하지 마세요 |
| 70% | +1% | −1% | +0.40% — 현실적으로 가능한 영역 |
| 55% | +3% | −1.5% | +0.98% |

그래서 목표를 하나로 고정하지 않고 **사다리(1%·1.5%·2%·3%)로 함께 채점**합니다.
"70%를 넘기려면 목표가 몇 %여야 하는가"를 추측이 아니라 기록으로 답하기 위해서입니다.

## 데이터는 맥북 밖으로 나가지 않습니다

토스 Open API 이용약관 **제5조 ③** — 시세정보는 "개인투자자 본인의 매매 목적에 한하여"
이용해야 하며 제3자 제공·배포·상업적 활용이 금지됩니다.

기준을 하나로 잡았습니다: **올린 내용으로 토스 시세를 복원할 수 있으면 올리지 않는다.**

| 사이트에 올라가는 것 | 맥북에만 있는 것 |
|---|---|
| 종목명·코드 (KRX 공개 정보) | 가격 전부 (진입가·손절가·목표가·현재가) |
| 셋업 이름, 선정 근거 서술 | 시가·고가·저가·종가, 분봉 원본 |
| 목표 %·손절 % (우리가 정한 규칙값) | 거래량·거래대금 절대값 |
| 판정 결과, 비용 차감 손익률 % | 호가·잔량 |
| 적중률·표본수·Wilson 하한 | 투자자별 순매수 주식 수 |

안전장치는 `publish.py`의 **화이트리스트**입니다. 허용 필드를 명시적으로 나열하고 나머지는
전부 버립니다. 업로드 직전 `assert_no_prices()`가 가격으로 의심되는 값이 남아 있는지 한 번 더 봅니다.
주문 API는 이 도구 어디에도 없습니다. 조회만 합니다.

## 설치

`설치.command`를 더블클릭하세요.

1. 토스 Client ID / Secret 저장 (권한 600 파일)
2. 연결 확인
3. [선택] 공시·뉴스 키 — OpenDART, 네이버 검색 API (둘 다 무료)
4. [선택] 사이트 업로드 — 먼저 저장소의 `stocks_schema.sql`을 Supabase SQL Editor에서 실행하세요
5. 자동 실행 일정 등록
6. [선택] 과거 분봉 소급 수집

키는 터미널에만 입력합니다. 채팅이나 웹페이지에는 절대 입력하지 마세요.

## 하루 일정 (한국시간)

| 시각 | 작업 | 내용 |
|---|---|---|
| 08:00 | `prepare` | 유니버스·수급·공시·뉴스·새벽 해외시장 수집, 후보 계획 생성 |
| **08:30** | `morning` | 관문 통과 셋업만 그날 추천으로 고정 |
| 5분마다 | `intraday` | 장중 실제 돌파 시점 감시. 장 시간이 아니면 즉시 종료 |
| 15:40 / 16:10 | `close` | 분봉 축적 + 계획 재현 채점 + 스코어보드 갱신 |
| 상시 | `viewer` | `http://127.0.0.1:8766` |

- 휴장일은 토스 공식 시장 캘린더로 자동 제외됩니다.
- `morning`은 **08:30~08:39 안에서만** 발행합니다. 맥북이 그 뒤에 깨어나면 그날은 건너뜁니다.
  지나간 시간에 맞춰 소급 생성하면 검증이 무의미해지기 때문입니다.

### 맥북은 켜져 있어야 합니다

토스 키가 이 맥북에만 있고 약관상 시세를 서버로 보낼 수 없어서, 수집은 여기서 돌아야 합니다.
토스 Open API의 허용 IP 설정 때문에도 고정된 환경이 필요합니다.

다만 매일 뭘 하실 필요는 없습니다. macOS launchd가 알아서 실행합니다.
터미널을 켜둘 필요도, 화면이 켜져 있을 필요도 없습니다. **로그인된 상태로 전원이 들어와 있으면** 됩니다.

잠자기에 들어가면 08:30을 놓칠 수 있습니다. 평일 아침 자동 기상을 걸어두세요.

```sh
sudo pmset repeat wakeorpoweron MTWRF 07:50:00   # 평일 07:50 자동 기상
pmset -g sched                                    # 현재 예약 확인
sudo pmset repeat cancel                          # 예약 해제
```

## 무엇을 추천이라고 부르는가

'예상 상승률'이 아니라 **실행 가능한 계획**입니다.

```
진입 조건 · 손절 폭 · 목표 · 유효 시간
예: 09:00~09:30 고가 돌파 시 진입 / 손절 −1.2% / 목표 +1.5% / 13:00까지 미발생 시 포기
```

시가 대비 종가 수익률은 실제로 그렇게 매매할 수 없어서 검증 대상이 되지 못합니다.

### 채점 방식 (보수적으로)

- 한 봉 안에서 목표가와 손절가를 **모두** 건드렸으면 **손절**로 처리합니다.
  1분봉으로는 순서를 알 수 없고, 유리한 쪽을 가정하면 검증이 거짓말이 됩니다.
- 진입은 돌파가에 1틱 불리하게 체결됐다고 봅니다.
- 모든 손익은 수수료·거래세·슬리피지를 뺀 값입니다. 계좌 수익률이 아니라 거래당 수익률입니다.

## 쓰는 데이터

| 출처 | 내용 |
|---|---|
| 토스 `/candles` | 종목 1분봉·일봉 |
| 토스 `/market-indicators/*/candles` | 코스피·코스닥 지수 (상대강도 기준) |
| 토스 `/stocks/*/investor-trading` | 외국인·기관·개인 순매수 |
| 토스 `/stocks/*/short-selling` | 공매도 비중 |
| 토스 `/stocks/*/program-trades` | 프로그램매매 순매수 |
| 토스 `/stocks/*/warnings` | 정리매매·단기과열·투자경고·VI (제외 필터) |
| 토스 `/orderbook` | 호가 스프레드 (프리마켓 측정용) |
| 토스 US ETF 일봉 | EWY·SOXX·QQQ·SPY·EWJ·FXI — 새벽 해외시장 |
| OpenDART | 공시 원문. 유상증자·전환사채·감자는 자동 제외 |
| 네이버 뉴스 검색 | 관련 기사 수, 제목·링크 |

**새벽 해외시장을 ETF로 받는 이유**: 08:30 시점에 미국장은 새벽 6시에 이미 끝나 있어,
그날 유일하게 완전히 확정된 최신 정보입니다. 일본·중국은 09:00 / 10:30에 열려서
전일 종가뿐이지만, 미국 상장 해당 국가 ETF는 새벽까지 거래되며 미국 투자자의 재평가를 담습니다.
무료 지수 CSV 사이트는 봇 차단이 걸려 있어 쓰지 않았습니다 — 우회하지 않습니다.

**한계**: ETF는 원지수와 다릅니다. 환율 효과와 미국 거래시간 재평가, ETF 자체 수급이 섞여 있습니다.

**미래 정보 차단**: 08:30 판단에는 그 시각 이전 데이터만 씁니다. 뉴스는 게시 시각과
수집 시각을 따로 저장하고, 게시 시각이 판단 시각 이후인 기사는 버립니다.

## 진입은 정규장에서만

프리마켓(NXT 08:00~)은 진입 추천에 넣지 않습니다.

- 호가가 얇아 스프레드가 넓습니다. 엣지가 0.3%인데 스프레드가 0.5%면 이론이 맞아도 손해입니다
- 현재 전략이 정규장 개장 레인지 기준입니다
- 검증할 과거 표본이 0건입니다

대신 `premarket.py`가 **매일 스프레드와 호가 두께를 측정**해 기록을 쌓습니다.
그 기록이 관문을 통과하면 그때 추천에 넣습니다. 의견이 아니라 데이터가 결정합니다.

## 명령어

```sh
python3 daily_runner.py prepare     # 08:00 준비
python3 daily_runner.py morning     # 08:30~08:39 에만 동작
python3 daily_runner.py close       # 마감 축적 + 채점
python3 intraday.py                 # 장중 감시 1회
python3 history.py backfill         # 과거 분봉을 보관 한계까지 소급 수집
python3 history.py probe            # 분봉 보관 범위 확인
python3 publish.py recent           # 최근 기록 사이트 업로드
python3 schedule.py status          # 자동 실행 상태
python3 schedule.py uninstall       # 자동 실행 해제
```

`backfill`은 하루씩 거슬러 올라가며 받아보고, 거래일 연속 3일이 비면 보관 한계로 보고 멈춥니다.
받아온 봉의 날짜가 요청한 날짜와 다르면 저장하지 않습니다 — 보관 범위 밖 응답을
그날 데이터로 착각해 저장하면 검증이 오염되기 때문입니다.
호출 간격이 1.1초라 오래 걸리지만, 이미 받은 날짜는 건너뛰므로 중단 후 다시 실행하면 이어집니다.
**프리마켓 스프레드는 소급할 수 없습니다** — 과거 호가 조회 API가 없어 오늘부터만 쌓입니다.

실행 기록: `~/Library/Logs/BorakwanStocks/`
저장 위치: `~/Library/Application Support/BorakwanStocks/`

## 현재 셋업

| 이름 | 조건 |
|---|---|
| `orb_flow` | 전일 시장 대비 강세 + 외국인/기관 순매수 + 거래량 1.2배 이상 |
| `orb_strict` | 위 조건 + 20일 고가의 95% 이상 + 거래량 2배 이상 + 공매도 비중 15% 이하 |

공통 제외: 1,000원 미만, 변동성 6% 초과, 정리매매·단기과열·투자경고·투자위험 지정,
유상증자·전환사채·감자 등 악재 공시.

조건을 적게 유지합니다. **조건이 많을수록 과거에는 잘 맞고 앞으로는 안 맞습니다.**
