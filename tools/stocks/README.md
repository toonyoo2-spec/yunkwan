# 주식 기록 수집기 (맥북 전용)

`stocks.html` 화면에 들어갈 기록을 만드는 맥북 쪽 도구입니다.
매일 아침 예상 상승률을 고정하고, 장 마감 후 실제 결과와 비교해 오차를 남깁니다.

## 중요: 데이터는 맥북 밖으로 나가지 않습니다

토스 Open API 이용약관 **제5조 ③** — "고객은 회사에서 제공하는 시세(국내주식, 해외주식)정보를
개인투자자 본인의 매매 목적에 한하여 이용하여야 하며, 제3자에게 제공하거나 배포 또는 상업적으로
활용해서는 아니 된다."

따라서 이 도구는:

- 수집한 시세와 분석 결과를 `~/Library/Application Support/BorakwanStocks/` 안에만 저장합니다.
- GitHub, Supabase, 그 밖의 어떤 서버로도 업로드하지 않습니다.
- 화면은 `http://127.0.0.1:8766` 루프백에서만 열리며 외부 접속을 거부합니다.
- 주문 API는 사용하지 않습니다. 조회(읽기)만 합니다.

`yunkwan.cloud/stocks.html`에는 시세가 저장되어 있지 않습니다. 그 페이지는 껍데기이고,
실제 기록은 이 맥북에서 열거나 JSON으로 내보내 본인 기기에서 불러올 때만 보입니다.

## 설치

`설치.command`를 더블클릭하세요. 세 가지를 한 번에 합니다.

1. `daily_runner.py setup` — 토스 Client ID / Secret을 사용자 전용 파일(권한 600)에 저장
2. `daily_runner.py check` — 연결 확인
3. `schedule.py install` — 자동 실행 일정(launchd) 등록

Client ID와 Secret은 터미널에만 입력합니다. 채팅이나 웹페이지에는 절대 입력하지 마세요.

## 하루 일정 (한국시간)

| 시각 | 작업 | 내용 |
|---|---|---|
| 08:00 | `prepare` | 거래대금 상위 보통주에서 후보를 뽑고, 과거 정규장 시가→종가 기록을 모읍니다 |
| 08:30 | `morning` | 그날의 예상 상승률을 고정해 저장합니다 |
| 15:40 | `close` | 정규장 종가를 확인해 예상 대비 실제를 평가합니다 |
| 16:10 | `close` | 15:40에 종가가 덜 채워졌을 때를 위한 재시도 |
| 상시 | `viewer` | `http://127.0.0.1:8766` 개인 기록 화면 |

- 휴장일은 토스 공식 시장 캘린더를 보고 자동으로 건너뜁니다.
- `morning`은 **08:30~08:39 안에서만** 예측을 만듭니다. 맥북이 자고 있다가 그 뒤에 깨어나면
  그날 예측은 만들지 않습니다. 지나간 시간에 맞춰 예측을 소급 생성하면 검증이 무의미해지기 때문입니다.
- 맥북이 꺼져 있거나 인터넷이 끊겨 있으면 그날 기록은 비어 있게 됩니다.

## 확인과 해제

```sh
python3 schedule.py status      # 등록 상태 확인
python3 schedule.py uninstall   # 자동 실행 해제
```

실행 기록: `~/Library/Logs/BorakwanStocks/`

## 계산 기준

- 실제 상승률 = (정규장 종가 ÷ 정규장 시가 − 1) × 100
- 오차 = 실제 − 예상 (%p), 작을수록 좋습니다
- 방향 적중 = 예상과 실제의 부호가 같은지
- 기준선 = "0%로 예상했을 때의 오차". 우리 예상이 이보다 못하면 예측이 아무 값어치가 없다는 뜻입니다

계좌 수익률이 아닙니다. 수수료·세금·체결 슬리피지·투입 비중은 반영되어 있지 않습니다.

## 현재 예측 모델의 한계

`regular-session-mean-shrink-v1` — 과거 20거래일 정규장 시가→종가 수익률의 평균을
0% 방향으로 축소(shrink)한 값입니다.

이건 **검증된 전략이 아니라 비교 기준선**입니다. 공시·뉴스·거래량 급증·상대강도·호가 같은
실제 단타 근거는 아직 하나도 들어가 있지 않습니다. 우선 이 기준선의 오차를 며칠 쌓아두고,
새 조건을 넣었을 때 오차가 실제로 줄어드는지로 개선 여부를 판단합니다.

## 수동 실행

```sh
python3 daily_runner.py prepare
python3 daily_runner.py morning   # 08:30~08:39 에만 동작
python3 daily_runner.py close
python3 local_view.py             # 화면만 따로 띄울 때
```

`toss_connect.py`(연결 확인)와 `toss_collect.py`(후보 1회 수집)는 인증정보를 저장하지 않고
실행할 때마다 직접 입력받는 단독 실행용 도구입니다.
